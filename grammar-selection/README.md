# 语法选目记录

这份目录回答一个问题：**「你的 JLPT 语法清单是怎么定的？」**

产出物是一张按等级累积的选目表。它本身就是证据 —— 每条语法点写清楚**为什么收、
按哪个公开来源收**，所以选目是自己编的，不是从某一本教辅照搬的。
详细判据见 [docs/CONTENT_RIGHTS.md](../docs/CONTENT_RIGHTS.md) 的「语法说明」一节。

## ⚠️ 一条铁规矩：表里不存题干原文

只记**考点**（「～ながら」）和题号定位（`2018-N5-問題1-13`），
**不抄题干、不抄选项、不抄例句**。

理由：考点是事实（这场考试考了什么），事实不受著作权保护；题干和选项是表达，抄了就是复制。
按这条写出来的表**可以公开出示**，那正是这张表存在的全部意义 —— 一张不能给人看的证据链等于没做。

同一条规矩适用于任何来源：出題基準、公式問題集、教材大纲，都只提取「哪个语法点属于哪一级」
这个事实，不搬文字。

## 字段

| 列 | 说明 |
|---|---|
| `来源` | 上表的代号 |
| `定位` | 年份-等级-大题-题号，可回查 |
| `考点` | 这道题实际考的语法点（我们自己的说法，不是原书的） |
| `本库对应` | `grammar_seed.json` 里的条目名；没有就写 `——` |
| `状态` | `已有` / `缺` / `分级不符`（官方在这一级考、我们放在别级） |

## 怎么用这张表

1. **`缺`** → 补进清单，来源栏写 `OFFICIAL-2018` 等
2. **`分级不符`** → 按官方那一级改，这是自己做的分级判断，要记下来
3. **`不收`** → 来源里出现过但我们判断不进语法库的，必须写下理由。
   例：`いっしょに`、`また` 只在真题里作为**副词**考过，いろどり / まるごと 两份文型表都不把它们
   当文型收 —— 判定为词汇不是语法，归到词库那边。**这类判断正是「选目是自己做的」的体现，
   所以理由必须落纸。**
4. **反向**：清单里有、但所有来源里一次没出现过的 → 降档或删。
   **删完每级条数自然就不是 120/130/140/150 了**（见 CONTENT_RIGHTS 里那个等差数列）
