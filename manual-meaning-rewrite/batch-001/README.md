# 首批中文释义重写（精简版）

本目录是独立的人工审核批次，不属于正式词库，也不会被学习页面加载。

- `meanings.json` 包含 300 条重新独立撰写的精简释义。
- 首个义项优先采用背词时一眼可识别的短译，只有必要时才用分号补充第二义项。
- 动词优先保留动作感（如“转阴”），形容词在需要时保留“的”以体现词性；时间关系按中文自然表达处理（如“在那以后”）。
- 选择条件是正式词库中旧释义长度超过五字；旧中文只用于筛选，未作为写作输入。
- 创作阶段只使用词条 ID、日语词形、假名和日语词性信息。
- 未修改 `frontend/public/nihongo.db`、种子数据、用户学习记录或同步数据。
- 这些释义先供人工检查，未视为已批准内容。
