# 收集日 ShuShuGo

收集日是一款帮助你持续学习日语的应用。它把单词、语法、例句和复习安排放在一起，让你可以按自己的节奏积累日语知识。

## 你可以用它做什么

- **学习 JLPT N5–N1 单词**：通过卡片认识词义、读音和例句，并记录自己的掌握情况。
- **复习学过的内容**：应用会根据答题记录安排复习，也会把答错的内容加入错题复习。
- **学习日语语法**：浏览语法说明和例句，按等级查找和学习。
- **查看学习记录**：回顾学习进度与统计，了解自己持续学习的情况。
- **离线学习**：词库和学习进度保存在设备上；没有网络时，基础学习仍可继续。

应用还包含学习模式、词汇查找和个性化设置等功能。部分功能可能仍在开发或验证中，实际提供情况以应用内界面为准。
