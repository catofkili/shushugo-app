# 收集日 ShuShuGo

收集日 ShuShuGo 是一款为日语学习设计的应用。它把手写整理的疑难辨析、贴合日语特点的练习、灵活的学习方式和自动安排的复习任务放进同一套学习流程，帮助你看懂细微差别，也记住学过的内容。

## 产品亮点

- **手写疑难辨析**：把容易混淆的词放在一起，说明词义和用法上的区别。
- **查词汇量**：通过词汇测试估算日语词汇量，看看自己积累到了哪里。
- **为日语设计的练习形式**：从词义回忆日语、由日语回忆词义、辨析近义词、练习语法和汉字读音等角度检验掌握情况。
- **一字多音**：结合词语说明同一个汉字在不同语境中的读音和用法。
- **灵活、可个性化的学习模式**：按需要切换经典、混合、快速、错题、反向或汉字读音等模式，也可以从词库挑选自己的学习清单。
- **组队学习**：和队友查看每日进度、互相鼓励，一起保持学习节奏。
- **算法安排每日任务**：根据作答和记忆情况安排到期复习，让每天的学习有计划可循。
- **离线学习**：词库和学习进度保存在设备上；没有网络时，基础学习仍可继续。

应用也提供日语词汇、语法、例句和学习记录，方便你在同一处查找、练习和回顾。
