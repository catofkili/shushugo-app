# 收集日官网首页：同类产品观察

2026-09-25 查看各产品官方首页。记录可直接用于首页决策的做法，不照搬品牌文案、插画或未核实的效果数字。

| 产品 | 首页可见做法 | 收集日可借鉴的部分 |
| --- | --- | --- |
| [Duolingo](https://en.duolingo.com/) | 大角色插画、一句价值主张、明确的开始入口，后面再解释学习方式。 | 第一屏只回答“学什么、为什么来、从哪开始”。 |
| [Busuu](https://www.busuu.com/) | 从学习新语言带来的机会切入，逐段说明课程、社区、口语等价值。 | 卖点放在学习场景里讲，不堆功能名。 |
| [LingoDeer](https://www.lingodeer.com/language/japanese) | 日语专页突出口语、语法、复习和离线能力，并给出直接开始入口。 | 单独讲清日语学习路径；保留准确的离线说明。 |
| [WaniKani](https://www.wanikani.com/) | 先讲专攻汉字和词汇，再解释部首、汉字、词汇、间隔复习的顺序。 | 用“从新知识到复习”的顺序解释方法。 |
| [Renshuu](https://www.renshuu.org/) | 首页让访客直接试题型和学习路径，再介绍产品。 | 放一张可点开的示例词卡，让访客先体验一次。 |
| [MaruMori](https://marumori.io/) | 用地图、章节和角色展示分层的日语学习旅程。 | 借鉴“有路径”的表达，不复制冒险地图或美术。 |
| [Memrise](https://www.memrise.com/) | 按旅行、考试、工作等学习目的讲产品使用情境。 | 文案从学习者需求出发，避免功能目录式介绍。 |

## 本站选择

首页主张为“把日语，收集成每天的进步”，紧接可用的网页版入口。中段展示与小程序介绍页一致的四项能力：JLPT N5–N1 词汇、语法与例句、按作答安排复习、离线保存基础学习。访客可点开一张不记录数据的示例词卡。末尾明确项目持续开发、平台版本以实际发布为准。

首屏和内容区使用 `~/收集日/未命名文件夹/` 中的水豚素材已经裁出的仓库品牌图，不直接使用带拼版标题的源图。官网静态部署与现有 GitHub Pages 学习 App 分开，避免 `/shushugo-app/` 构建路径和 `Disallow: /` 设置影响主域首页。
