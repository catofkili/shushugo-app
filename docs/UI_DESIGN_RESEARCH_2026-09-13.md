# ShuShuGo UI 重构前调研

调研日期：2026-09-13。本文回应「先搜索成熟平台的 UI 设计理念，学习后再重构」；记录来源、适用边界、现有源码线索及设计建议。调研已完成，界面重构尚未实施。

本次只读查看前端源码，新增本文；没有打开、刷新学习页，没有启动或修改 5173 服务，没有执行应用构建。后续所有可运行原型与界面改动必须使用独立目录和独立端口。仅换端口但仍编辑原目录，会触发原学习页面的 HMR，不构成隔离。

## 1. 设计方向

建议保留新绿、奶油底、水豚棕和水豚角色，形成温暖、清晰、适合长时间阅读的学习界面。视觉重点由字号、位置、留白和对比共同表达；装饰集中在问候、阶段完成和成就时刻。

参考组合：多邻国的学习引导与品牌亲和力、Linear 的布局和密度控制、Apple 的阅读与交互规范、Material 的重点表达。不同产品的经验用于提出设计假设，不能当成 ShuShuGo 学习效果已经提升的证据。

## 2. 成熟产品中值得采用的原则

### 多邻国：把跨页面一致性做成系统

官方核心标签页改版复盘指出，标题、字体层级、间距的不一致会累积成整体不精致。团队比较了醒目色块、柔和渐变、卡片模块、极简留白四种方向，最终按页面用途安排标题层级，并用留白替代部分容器。统一需要兼顾用途，简化需要兼顾清晰度。[官方复盘](https://blog.duolingo.com/core-tabs-redesign/)

我们的应用：为首页、词库、语法、个人页定义共同的标题位置、正文层级、工具栏和间距。容器用于明确分组、操作边界或浮层关系；普通段落与列表优先通过间距组织。水豚插画按用途出现，避免每个页面都放一个占据大块空间的装饰头图。

2022 年首页路径改版的原始问题是学习者不确定下一步学什么。课程引导和复习被组织在同一条路径中。[首页改版说明](https://blog.duolingo.com/new-duolingo-home-screen-design/)

我们的应用：首页清楚显示当前计划和继续学习入口，同时保留主动选词与模式选择。路径只是多邻国针对其课程的一种解法；现有 FSRS 学习队列无需为了外形相似而改成闯关地图。

### Linear：先处理整体层级，再处理局部装饰

2024 年复盘强调减少视觉噪声、保持对齐、协调导航层级与密度，并在多种视图、主题和运行环境中验证共同规则。[官方 UI 改版复盘](https://linear.app/now/how-we-redesigned-the-linear-ui)

我们的应用：导航、工具栏和学习正文有明确的视觉优先级。词库与设置使用可扫描的行式布局，学习页留出阅读空间；相同功能的按钮和标题跨页面保持同样的外观与位置关系。借用布局纪律时仍保留我们的暖色与角色。

### Apple：颜色表达含义，阅读和操作需要可验证的细节

Apple 建议保持颜色语义一致，避免仅靠颜色传达状态，并在浅色、深色等环境下检查可读性。[HIG 颜色](https://developer.apple.com/design/Human-Interface-Guidelines/color)

其 UI 基础指南要求内容适应屏幕、避免横向滚动，强调对齐、行间距以及可点击区域；触控目标建议至少 44 × 44 pt。[UI Design Dos and Don’ts](https://developer.apple.com/design/tips/)

我们的应用：新绿优先用于主要动作与选中状态，评分仍通过文字区分含义。移动网页初步以至少 44 × 44 CSS px 的交互区域进行设计并在实际 WebView 验证；这是项目设计目标，不能把 CSS px、物理像素和 iOS pt 混为一谈。字号优先保证中文与日语阅读，不能把最低字号当成正文推荐值。

### Google Material：有表现力的设计也可以帮助操作

Material 3 Expressive 官方研究介绍使用颜色、形状、尺寸、动效和分组引导注意，并报告了 46 项研究、超过 18,000 名参与者。其结果属于 Google 对特定设计与任务的研究。[官方研究介绍](https://design.google/library/expressive-material-design-google-research)

我们的应用：开始学习按钮可以更鲜明，完成反馈可以更有角色感，其他工具维持较低视觉权重。表达强弱应匹配任务重要性。不能把报告中的识别速度改善直接换算成背词速度或记忆效果，也不需要因此引入 Material 组件库。

## 3. 学术研究能支持什么

### 视觉复杂度与熟悉结构影响第一印象

Tuch 等人在 2012 年的两项实验中，用网站截图研究视觉复杂度与典型性；低复杂度、符合类别预期的页面整体更受审美偏好。[论文与作者摘要](https://research.google/pubs/the-role-of-visual-complexity-and-prototypicality-regarding-first-impression-of-websites-working-towards-understanding-aesthetic-judgments/)

应用假设：清楚的导航、熟悉的列表、合理的留白和较少的竞争焦点，有助于形成整洁观感。研究测量的是截图第一印象，不能推出所有页面都要低信息密度，也不能推出学习收益。

### 无关的有趣细节可能干扰学习

Sundararajan 与 Adesope 的 2020 年元分析指出，与学习无关的有趣信息可能损害学习，效果受材料、呈现方式和学习节奏等因素影响。[论文公开摘要](https://link.springer.com/article/10.1007/s10648-020-09522-4)

Cheng 等人于 2026 年发表的元分析汇总 50 项研究、177 个效应量，公开摘要报告整体小幅负效应（g = −0.16）。[论文公开摘要](https://link.springer.com/article/10.1007/s10648-025-10099-z)

上述两篇本次核查的是出版方公开摘要，没有声称读完付费全文。应用假设：题面周围持续跳动、与内容无关的装饰应克制；庆祝尽量放在任务完成的自然停顿处。相关示意图、帮助理解的视觉提示和操作反馈仍有价值。不能由此判定水豚角色本身会降低记忆效果。

### 保持颜色不变，也能改善可读性

按 WCAG 的 sRGB 相对亮度公式计算以下纯色、不透明组合。普通文本最低对比度通常为 4.5:1，大号文字为 3:1，另有规范规定的例外。[W3C 对比度说明](https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html)

| 前景 / 背景 | 对比度约值 | 设计含义 |
| --- | --- | --- |
| 白字 / `#7EBE4F` | 2.242:1 | 不能直接拿来做普通按钮文字 |
| `#2A3B18` / `#7EBE4F` | 5.391:1 | 现有深字方案能保留主色又达到普通文字门槛 |
| `#9A8A78` / `#FBF5E9` | 3.079:1 | 重要小字号说明需要换用已有更深文字色 |
| `#6B5A48` / `#FBF5E9` | 6.079:1 | 现有次级正文色可用于可读的辅助文字 |
| `#3A2E22` / `#FBF5E9` | 12.134:1 | 保留清晰的主要阅读层 |

这是色对计算，非已完成全站无障碍检查。实际页面存在透明度、渐变、继承和主题覆盖，必须检查最终前景与背景。数值是展示近似值，不能用四舍五入跨越合格门槛。

## 5. 转成可执行的设计要求

以下是本项目的候选规则，不是任何论文规定的万能数值。

1. 标题、正文、辅助文字、词头形成有限而清楚的字号体系。界面使用稳定的中日文字体回退；日语词头可保留有辨识度的字体，长例句优先可读性。振假名、长词、混合中日文需要单独检查。
2. 间距先以 4/8/12/16/24/32 px 为候选尺度；圆角按小控件、内容卡片、浮层分级，原型验证后统一。
3. 首页第一眼能找到继续学习；主要动作与导航选中状态允许使用主色，但在尺寸、位置上明确区分。
4. 单词学习页围绕题面、答案和评分组织，发音、笔记、辨析入口靠近对应内容。评分保持相近的操作权重，避免通过巨大绿色按钮暗示用户总选“认识”。
5. 词库、收藏、设置强调对齐和扫描效率；语法详情强调阅读段落、接续和例句层次。统一视觉规则不等于每种页面都套同一张卡片。
6. 首页与完成页可以有角色表达；高频翻面和评分反馈短促、不挡下一次操作。沿用现有动效偏好，系统减少动态效果优先。
7. 每个交互都包含默认、按下、焦点、禁用等必要状态；数据页面覆盖加载、空内容、错误和恢复状态。真实可用性与静态样稿一起验收。

## 6. 后续重构的覆盖范围与验收

实施顺序：共同样式与应用外壳 → 首页与单词学习 → 快速学习与语法 → 词库、收藏、辨析、设置与个人页 → 周报、动物园、弹窗及边界状态。先建立代表性画面与规则，完成后的覆盖范围仍须检查全站，不能只改首页就宣称 UI 重构完成。

验证方法：

- 在独立目录保存当前前端版本，包含本次读取到的未提交和未跟踪相关文件；排除个人存档、凭据和无关产物。只使用独立端口及测试数据，避免新进程覆盖原目录的 `.local/live.db`。
- 同时比较手机、平板和桌面布局；建议覆盖 360/390/768/1440 CSS px，以及浅色、深色和减少动态效果。
- 用真实形态的长日语词、振假名、多行释义、长例句检查换行与遮挡；大字体下按钮、词典浮层与底部操作仍可访问。
- 用“从首页继续学习”“翻面并评分”“查一个词”“找到设置”验证可发现性、完成步骤及误触；漂亮截图与完成任务同样重要。
- 只对改动涉及的行为执行适当回归检查。保留学习记录、FSRS、翻面后评分、撤销、草稿和返回路径的既有语义。
- 对每种页面形态保存改前改后截图并逐项检查。类型检查或构建通过，不能替代视觉检查或真机触控验收。

当前产出是研究依据及重构方向；没有实施上述页面改造，也没有把设计假设当成已验收结果。
