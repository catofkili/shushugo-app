# 辨析卡「判断要点」编写要求

适用范围：`frontend/src/data/confusion_distinction_reviews.ts` 中进入辨析卡的人工区别稿。先按本要求逐组审校，再改内容；本文不是批量改稿的授权。词条释义、题面和判断要点各司其职：释义回答“这个词什么意思”，判断要点回答“面对这一组词，凭什么选这个而不选另一个”。

## 一、每组必须交付什么

1. **一条可操作的共同判据。** 先指出学习者在日语句子里实际能观察到的线索，例如谁作主语、谁作宾语、接什么助词、动作由谁发出、对象与结果是什么、惯用搭配或语体限制。必须覆盖本组所有待辨成员；不能只解释其中一个词。
2. **每个成员的一条独立提示。** 点明该词在共同判据下要看哪个句法、助词、搭配或语体线索；补上释义中没有的适用边界，不能只把词典释义再写一遍。
3. **必要的边界。** 若两个词在某些语境都成立，应说明视角或语感如何变化；若没有稳定的排他判据，不得捏造“只能用 A”的规则。重新核定 `major` / `interchangeable`；不满足现有辨析卡准入条件的组，不为凑卡强行写成 `major`。

## 二、写作和展示约束

- 当前卡片把 `summary` 的**第一个全角或半角分号之前**直接显示为「判断要点」。所以第一段必须是独立成立的共同判据，不得写成“甲表示……；乙表示……”。判据内部不用分号，也不要先铺空泛导语。
- 后续用全角分号 `；` 隔开逐词说明，明确写出每个词形，让现有 `distinctionNotesFor()` 能拆到相应成员卡。提交前实际检查拆分结果；不能让任一成员缺注、把甲的说明挂到乙上，或让成员卡重复整条判断要点。
- **背词页已有例句，不要在手写稿里再抄一遍。** `DistinctionSheet` 从成员的 `exampleJp` / `exampleMeaning` 显示例句和译文；未翻面时隐藏当前词，翻面后才显示当前词的答案。要点和逐词提示要能说明该看什么，同时不泄漏被隐藏的答案，也不依赖未显示的例句才能读懂。混合学习辨析卡不显示这些例句，因此要点和逐词提示本身也必须说得清楚。
- 判据和例子须适合本组的**实际义项**。同形词、不同读音、近义词的区别不能从字面或中文翻译硬推；先核对词义、词性、句法和自然搭配。不要把「自动词」简单写成“无人主动做”，也不要把「他动词」简单写成“有意做”。
- 说清适用范围，不用“一律、只能、绝不”等未经核实的绝对措辞。若原稿涉及多个常用义项，不能为制造单一判据而删义项；必要时分义项说明或承认这一组不适合做单选辨析。
- 语言要让学习者在翻面后能复核自己的回想：先看什么 → 怎样判断 → 两个近似句各为何成立。不要用“前者/后者”代替词名，也不要堆「主动/自己/区别使用」这类无法落到句子里的标签。

## 三、截图这一组的示范

**不合格：**「分かれる表示整体自己分开或分成几组；分ける表示主动分配、分开或分类。」卡片只把前半句显示为判断要点，下面的成员说明又重复这两句释义。更严重的是，“自己/主动”容易让人误以为分组是否出于人的意志是选择标准。

**符合要求的写法示意，落库前仍须逐句审校：**

> 先找句中被分的整体：描述它分成几部分时用「が／は」作主体，描述有施事把它分组、分类或分配时用「を」标出对象。；分かれる：不以人的意志为判据，人群也可有意分组，句子仍把人群作主体；分ける：受影响对象用「を」，分类标准常用「〜ごとに」，分配去向可用「〜に」。

背词页会按词显示现有释义和例句，因此这里不重复抄例句；这些注记补的是助词、句法角色和搭配线索。正式审校仍须核对相关义项，避免用一个例子冒充全词规则。

## 四、逐组验收

审稿者应不看成员释义，只看「判断要点」就能说出这组词的选择依据；再读每个成员的日语例句，能指出支撑该依据的具体词、助词或搭配。把两个词互换后，必须能说明是语法、所述事件、视角、语体哪一项变了；若基本不变，就不得称为不可互换。最后按页面实际的首分号截取和逐词拆分检查展示结果，而不只检查源文件里“写了两句话”。
