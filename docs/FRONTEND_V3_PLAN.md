## 0. 「火苗方向」是什么

火苗之所以看起来对，是因为它同时做到了四件事。v3 把这四件事推到全站：

1. **一个有性格的主角，而不是一堆贴纸**：火苗有表情、会跳、会长大，一屏里它就是视觉中心。
2. **状态写在形状和颜色上**：亮 / 金 / 灭一眼可辨，不靠文字解释。
3. **每个时刻都有编排**：点燃、翻牌、格子依次亮、盖章，有先后、有回弹，2–3 秒讲完一个小故事。
4. **基础样式就是终态**：动画只负责「从起点走到终态」，减少动效 / 小程序掉帧时画面依然完整。

## 1. 硬规则（全站）

### 1.1 一屏一个主角
- **一屏（首屏 812px 高）里吉祥物最多一只**。主角可以是吉祥物、火苗，或一张主题插画，三选一。
- 功能入口、工具格、模式卡用**物件图标**（书、卡片、对话气泡、鸟居、放大镜……），**不画水豚**。
  现在「学习工具」十格每格都是一只水豚——这就是作者说的「三四个吉祥物挨着」。
- 同一屏里**同一张图不许出现两次**（开口练习 / 疑难辨析、JLPT 刷题 / 基础语法现在共用一张）。

### 1.1b 少开框、少二级界面（作者 10-14 看了火苗详情页第一版之后补的）
- 原话：「完全可以不为最长连续和累计学习天数开框，直接放到最上面去或者和日历结合……太多二级界面太啰嗦了」。
- **一个数不配一张卡**。次要的数（最长、累计、进度）并成主角下面的一行事实，用细分隔线隔开，不画框。
- **同一件事不说两遍**：大数字已经写了「6 天」，旁边的吉祥物气泡就不要再说「连续 6 天」。
- **能并进主区域的就不要另开一块 / 另开一页**：里程碑并成一条带站点的线，日历直接铺在页面底色上，规则缩成页脚一行。
- 判据：一页里的白卡数量越少越好；一张卡里只装一组需要一起看的东西。
- 火苗详情页第二版（`components/streak/StreakPageView.tsx`）是这条的样板；**第一版不是**。火苗这个角色和它的庆祝编排仍是方向。

### 1.2 不用 emoji
- 界面上不再出现任何 emoji（彩带的 🎉✨、火苗的 👑、组队队徽的 🌱🐿️🦉 等）。替换顺序：
  生成的小图（有性格的位置）→ lucide 图标（功能位）→ 纯 CSS 形状（彩带碎片、星星这种装饰）。
- 日志里的 ✅❌、CSS 注释里的 ⚠ 不算界面，不用改。

### 1.3 图片：放开生成，但要像一家人
- **作者 10-14 明确放开**：可以让 GPT 以现有原图为参考生成新图。这一条**取代** `interface-and-design-system.md` 里
  「吉祥物全部是作者的原图，不许再画 SVG 顶替」那句里「不许生成」的部分——仍然**不许用 SVG / canvas / 代码画图顶替**，要图就用图像生成。
- 风格基准：`frontend/public/brand/sheet/` 的现有原图（奶油底、柔和扁平、深棕细描边、暖色）+ 火苗（圆润水滴、深棕描边）。
  新图拿这些当参考图喂给生成工具。**图里不许有任何文字、字母、数字**。透明底 PNG。
- 占位图（加载不出来的、示意用的、借用别处的）全部换成生成的专属图。
- 小程序：每张图要决定放哪个包（主包余量见 `docs/claude/release-and-deployment.md`），贴纸按包登记（`taro-spike-2/scripts/sync-brand-assets.mjs`）。

### 1.4 动效语言（tokens 写进 `design.css`，组件只引用 token）

| token | 值 | 用在 |
|---|---|---|
| `--ds-dur-fast` | 120ms | 按下、选中、hover |
| `--ds-dur` | 220ms | 弹入、颜色切换、反馈条滑入 |
| `--ds-dur-slow` | 420ms | 卡片入场、翻牌、进度回弹 |
| `--ds-ease-spring` | `cubic-bezier(.34,1.56,.64,1)` | 一切「好事」：弹入、涨进度、数字落定 |
| `--ds-ease-out` | `cubic-bezier(.2,.8,.2,1)` | 位移、淡入 |
| `--ds-stagger` | 60ms | 列表 / 格子依次入场的间隔 |

固定动作（全站同一种做法，不各写各的）：
- **按下**：3D 底边按钮按下沉、松开回弹（已有 skins.css 的 lip，检查所有主操作、选项卡片都用上）。
- **入场**：页面主体淡入 + 上移 8px；列表 / 格子按 `--ds-stagger` 依次弹入，**最多前 8 个**有延迟，后面的直接出现。
- **数上去**：所有「获得了多少」的数字（柚子、今天学了几个、正确率）从 0 或旧值滚到新值。
- **飞过去**：获得柚子时图标沿弧线飞到余额，余额被「撞」一下（放大回弹）。
- **先点这个**：一屏里最该点的那个入口（今天的大卡「开始」）有一个上下浮动的小气泡或呼吸光，**一屏只有一个**。
- **稀缺时刻才放彩带**：满分、里程碑、清完计划。平常的答对不放。
- 减少动效（`[data-motion="reduced"]` / `prefers-reduced-motion`）：拿掉循环和入场，停在终态；数字直接显示终值。

### 1.5 每一次作答都有一套反馈（所有题型一致）
声（`zoo-sounds`）+ 震（`haptics`）+ 色（底部反馈条）+ 连对标签。现在只有单词页和组队页有声音和震动。
