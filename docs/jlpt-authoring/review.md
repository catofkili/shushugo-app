# 审校任务：把一份手写的 JLPT 模拟题当考生做一遍，然后改好

上一位作者按本文件下面附的规则手写了一份题，放在 `questions.json`。你是**独立审校**，
没有参与出题。你的工作是把这份题审到可以交给主编验收的程度：有问题的直接改，改不好的标出来。

## 硬限制

- 只在「本次任务」指定的目录里写文件。仓库只读，不提交，不起服务器。
- 不许读任何真题、市售题集（包括 `~/日语题/`）或网上题库。修改题目时也只能用我们自己的词表和语法表。
- **动手之前先把 `questions.json` 原样复制成 `questions.draft.json`**，之后只改 `questions.json`。

## 步骤

1. **盲做一遍。** 逐题只看 `stem`、`passage` 和 `options`，**不看** `answer`、`explanation`、`distractors`，自己选出答案，把你的选择和把握程度（确定 / 犹豫）记下来。然后再对答案。
2. **逐题检查**，下面这些都算问题：
   - 你选的和标准答案不一致，或者你在两个选项之间犹豫过；
   - 有干扰项代进去其实也说得通（这是最常见的毛病，文脈規定、言い換え、文法形式三类要尤其仔细）；
   - 排序题存在第二种自然的顺序；
   - 能靠形式排除选项：长度、活用形、送假名不一致，或者某个选项语法上明显接不上；
   - 题干日语不自然、有教材腔或中文腔，或者用了比本级更难的词；
   - `target` 的 id 查不到，或者不属于本级（用 sqlite3 查 `words` / `grammar_points` 核对）；
   - 题干照抄了词库里的 `example_jp`（用 `sqlite3 ... "SELECT id FROM words WHERE example_jp = '…'"` 抽查可疑的句子）；
   - 解析或干扰项说明写错了；
   - 格式不对（`[[…]]`、`（　　）`、★、`order`、`passage`）。
   - **题干比真题长，或者把答案解释了出来**（主编看初稿时发现的共性问题）。真题的题干通常只有一句：
     N5、N4 大约 10–25 字，N3 大约 20–40 字，N2、N1 可以长一些，但也很少超过两句。为了保证唯一正解而多写一句
     说明（比如写「一週間後に同じ内容を行う」来点明答案是「延期」），会让题目比真题容易得多。
     遇到这种题，压缩成一句，只留下锁定答案所必需的那一条线索；压缩之后如果出现了第二个正解，就换干扰项。
   - 读音题的干扰项拼出了日语里几乎不会出现的形式（比如词尾的「っく」「っき」：ほんやっく、いがっく），换成更像真实读音的变形。
   - 考点是冷僻词，真题不会考（比如「孵る」）：换成一个常见的同级词。
   - `explanation` 和 `distractors` 写成了日文：一律改成中文（用户是中文母语的学习者）。
   - 排序题整句只有四个空加一个「。」、没有固定的前后文：补上前后文。真题的排序题一定有一部分句子是给出来的，四块只填中间。
   - **主编验收卷 1 时改掉的 20 题，集中在下面几类，审校时逐条对照：**
     - 比较句、没有主语的句子最容易多解：「AはBより（大きい）」在价钱比较里也说得通；「来年は…住む（そうです）」没写主语就能读成转述。补主语或换掉干扰项。
     - 「〜ておく / 〜てみる」「〜はずだ / 〜かもしれない」「〜ことになった / 〜ことになっている」这类近义语法，只靠一点语感区分的，题干里要有能锁定的线索（比如「どんな味か」锁定「〜てみる」）。
     - 文章题里，因果（ため / から）和转折（のに / にもかかわらず）两种读法都能通的空，要在前后文加一个只支持一种读法的词（比如「もう」），或者换掉干扰项。
     - 排序题：前两块能互换不要紧，**只要 ★ 那个位置的答案不变**；如果某种合理的排法会让 ★ 位置换成另一块，就重切词块。
     - 压缩题干时，**不许删掉空后面属于句子本身的词**（语形成题「（　）可能」「（　）関係」里的「可能」「関係」被删过，结果四个选项都填不进去）。
     - 文章题的空号要按在文章里出现的先后编号。
   - **主编验收卷 2 时又改掉约 50 题，新出现的几类：**
     - 文法题题干里没有空（把正解直接写进了题干）；排序题题干末尾和选项里各有一个「ですか」。
     - 排序题有一种也说得通的语序让 ★ 换块（「買い物を店が閉まらないうちに済ませて」），或者 ★ 放在必然最后的谓语上。
     - 用法题的错句是胡话（「調整を受け取った」）或者只是同音字写法之争（温かい / 暖かい），换成近义词误用。
     - 时态没锁死：「旅行では花を（見たい）」没有「今度の」，「見たかった」也说得通。
     - 句子不自然：「母に作られた弁当」「橋を横断した」「次の船は出発した」「食事の前に…ご飯を食べます」。
     - 解析里夹日文（「は」「と読める」），一律改中文。
   - **主编验收卷 3 时改了 68 题，新出现的几类：**
     - 排序题四块都是整句步骤（「まず現場の声を集め、」「次に…整理し、」），考的是事情先后不是语法：重切成短词块。
     - 干扰项其实也说得通：「確認し（かねた）」在电话打不通时也成立；「（何人／いつ）参加できるかを電話で聞きました」完全通顺；「わからないけど晴れる（はずだ）ね」。
     - **压缩题干时删掉了锁定答案的线索**：「今日は月曜日」被压掉后，只剩「入口に月曜休み」推不出「开着的可能性为零」。压缩前先想清楚哪句是锁定线索。
     - 用法题错句只错在形式（活用、接续），不是词义用错。
     - 文章自相矛盾（「子どもだけが本を読む会」却去问大人能不能参加），文章和同份题撞场景。
     - 身份和语气不配（店员对客人说「〜ものではない」）；母亲每天「バスで学校へ行きます」这种说不通的人物。
     - 解析写成日文（N1 语汇一口气 6 题）。
3. **直接改。** 能改好的题当场改（换干扰项、改题干、重切词块，必要时整题重写）。改完的题要重新过一遍第 2 步。
   改不好的题保留原样，在 `doubt` 里写清楚问题。
4. 正解位置不用核对，也不要调换选项顺序：交给你之前已经打乱过，导入时还会再打乱一次。

## 交付：`review.md`

- 盲做的结果：一共多少题，和标准答案一致多少题，犹豫多少题；
- 改过的每一道题：题号、改之前的问题、怎么改的（写改前和改后的关键内容）；
- 仍然标着 `doubt` 的题和原因；
- 对这份题整体质量的一句话判断（和市售题集比，哪一类题型最弱）。

完成后最后一条消息只写一句：盲做一致率、改了几题、还剩几题 doubt。
