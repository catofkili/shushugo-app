  官网免费公开：`https://www.jlpt.jp/samples/sampleindex.html`（`sample2018/pdf/N{1-5}{V,G,R,answer}.pdf`）。
- **只用来对照题型、考法、题材、难度，不搬原文**（真题和问题集版权都不授权，见 `docs/JLPT_PRACTICE_SPEC.md`）。PDF 没放进仓库。

  再用脚本把我们 723 题对照应用词库 `jlpt_words_seed.json`（10,609 词）和 `grammar_seed.json`（769 条）的级别。

## 结论一览

| 维度 | 结论 |
| --- | --- |
| 考点级别 | ✅ 合适。考点词 / 语法点 99% 在本级，偏易的 11 个、偏难 0 个（但这是循环验证：出题时就是从这两张表挑的） |
| 题型配比 | ✅ N3–N1 与官方逐项一致；N1 文章题每卷 4 空（官方 5）、N2 語形成每卷 3（官方 5）；N5/N4 每卷是官方的 60–85%（有意缩短的话没问题） |
| 词汇题题材 | ✅ 合适。日常、学校、工作的短句，和官方同一类 |
| **题干难度来源** | ❌ N5–N3 偏难，难在考点以外（见 §1） |
| **读音题考法** | ❌ 只考清浊 / 长音 / 促音，缺官方一半的「认字」题（§2） |
| **表记题考法** | ⚠️ 我们多用同音字拼凑，官方用形近字和同义类字（§3） |
| **用法题考法** | ❌ 错句很多是荒谬替换，官方是「放到近义词位置」（§4） |
| **文法形式考法** | ❌ 几乎全是「四个不同语法点辨义」，缺敬语、会话体、同一词不同形（§5） |
| **文章题考法** | ❌ 官方考篇章（接续、指示、视点、文末），我们考本级语法点（§6） |

## §1 题干难度：难在考点以外

- 官方 N5/N4：文字・语汇的题干分写（单词间空格），非考点词几乎都写假名；**文法部分所有汉字都注假名**。N3 以上不注。
- 我们：刷题界面（`features/jlpt-practice/Question.tsx` 的 `Stem`）**不注音**；题干照常用汉字。
- ⚠️ **更正（作者 10-10 指出）**：初稿按应用词库 `jlpt_words_seed.json` 的级别说 N5 题干里「誕生日、冷蔵庫、押し入れ」是超纲词——**错了**。
  这些都是 N5 要学的词，是词库的级别标得偏高（N4/N3），**词库级别不能拿来判断词汇是否超纲**，那组统计作废。
  真正的问题是**汉字**：词在本级、字不在本级。官方 N5 考「れいぞうこ」这个词时写假名，因为「冷蔵庫」三个字不是 N5 汉字。
- 改法（建议，待作者定）：N5/N4 文法、文章题全题注音；文字・语汇题只给非本级汉字注音或改写成假名（读音题、表记题本身的考点词不能注）。

## §2 读音题

- 官方：约一半是「训读 / 常用词 + 同一语义场的真词干扰」，考的是「这个汉字是哪个词」：
  N5「雨」配 ゆき／はれ／くもり／あめ；N4「味」配 かたち／いろ／におい／あじ；N3「払って」配 くばって／はらって／かざって／ひろって；
  N1「賢い」配 するどい／かしこい／すごい／えらい。另一半才是清浊、长音、促音、拗音变体。
- 我们：几乎全是变体。干扰项碰巧是真词的比例：N5 9/63、N4 12/63、N3 17/72、N2 9/45、**N1 1/54**。
- 出题规则应加：每卷读音题约一半用训读词或常用和语，三个干扰项取同一语义场的真词（读音长度相近）。

## §3 表记题

- 官方：形近字（計画/訂画/計書、医者/匠者、貸/貨/資/質、輸出/諭出/輪出/論出、眠/眼）和同义类字（白/黒/赤/青、池/湖/港/波），
  偶尔同音（満足/万足）。N5 还有片假名（ワイシャツ/ウイシャソ）。
- 我们：多为同音字拼凑（進文、電死レンジ、信感線、校痛），对中文母语者几乎没有区分度。
- 规则应改：干扰项以形近字为主、同义类字为辅，N5/N4 每卷加 1 道片假名表记。

## §4 用法题

- 官方：**每个错句都是把考点词放到某个具体近义词该用的位置**，每题三个错句对应三个不同的近义词。例：
  N4 さいきん（误当「もうすぐ」「さっき」）、けんがく（误当 見物 / 調べる / 見る）；N3 沸騰（误当 気温が上がる / 熱が上がる）、
  出張（误当 旅行 / 出勤 / 参加）；N2 延長（误当 延期 / 増築 / 乗り過ごす）；N1 閑静（误当 安静 / 暇 / 静まる）、内訳（误当 予定 / 内容 / バランス）。
- 我们：N1 卷 2/3、N3 部分题已经是这种（人出↔人手、報酬↔代金/家賃/利息、迅速↔急速、被る↔はめる/かける/はく）；
  但 N5–N3 和 N1 卷 1 有大量荒谬替换（「駅への行き方を触りました」「授業が直りました」「花を飼った」）。
  返修时我把这些归为「干扰项弱，不算错」，**和官方对照后看，这是考法偏离，应当返修**。

## §5 文法形式

官方每卷与我们三卷合计对比：

| 级 | 官方每卷：会话体 / 敬语 / 同一词不同形 | 我们三卷合计：会话体 / 敬语 / 同一词不同形 |
| --- | --- | --- |
| N5 | 约 7 / 0–1 / 约 3（共 16 题） | 3 / 0 / 3（共 27 题） |
| N4 | 约 6 / 0–1 / 约 5（共 15 题） | 1 / 2 / 5（共 39 题） |
| N3 | 约 5 / 2 / 约 6（共 13 题） | 2 / 2 / 5（共 39 题） |
| N2 | 约 2 / 1 / 约 4（共 12 题） | 0 / 0 / 2（共 36 题） |
| N1 | 约 2 / 1–2 / 约 3（共 10 题） | 0 / 0 / 3（共 30 题） |

- 官方还常考副词、接续词（N5 まだ／また，N4 なかなか／もうすぐ，N2 そのうち，N1 もっとも），场景标签（（靴屋で）（電話で）（お知らせで）），口语体（してるんだって）。
- 官方「同一词不同形」的例子：あきらめ／あきらめて／あきらめる／あきらめた（～かける 的接续）、次第には／次第に／次第では／次第、知っていても／知られては。
- 我们 N1 文法几乎全是传统「N1 機能語清单」（そばから、が最後、ならいざしらず、にかこつけて、とあって……），而且都是「四个语法点辨义」。
  官方 2018 年版 N1 的 10 道里，清单型约 4 道，其余是接续、敬语、文脉、视点。
  **我们的 N1 难在冷门，官方难在接续和语境**；N2 同理。

## §6 文章题

- 官方题材：N5/N4/N3 是留学生作文（「我喜欢的饮料」「游泳」「日本人的天气话题」），N2 是杂志专栏（厕所标志的由来），N1 是小说家随笔（养猫与说明书）。
  我们 N5–N3 的个人记叙和官方一致；N2/N1 偏新闻报道体，可以加专栏、随笔这类带作者观点的文体。
- 官方空格考的是篇章：接续词（でも／しかし／けれども），指示词（これ／それら／そういう），视点与授受（言ってもらいました／言ってしまいました、教えてもらいました），
  文末语气（ご存じだろうか、のかもしれません、に違いない、認識させられる出来事だった），受身（使用されている）。
  多数空必须看上下文才能选。
- 我们：空格多是把本级语法点嵌进去（というもの、を皮切りに、べく、にかまけて……），大多只看本句就能做（普查已报「空格不需上下文」，这次对照确认是考法偏离）。

## 建议的返修顺序（按收益）

1. **N5/N4 题干注音**（改界面一次，全部题受益；N3 只处理超纲词）。
2. **改出题规则 `rules.md`**：§2–§6 写成规则，之后的卷 4 起按新规则出。
3. 存量返修：用法题错句（约 75 道里的一半）、文法形式补会话体 / 敬语 / 接续题（替换部分清单型题）、文章题至少把一半空改成篇章型、读音题换一部分为训读真词干扰。
