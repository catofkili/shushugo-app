## 各题型怎么出（重点在干扰项）

### 漢字読み（划线的汉字词 → 选读音，四个选项都是平假名）
- ⚠️ 下面这条「只做变形」已被 2026-10-10 对照官方样题后的第 32 条取代：**每套约一半读音题要用真词干扰**，见文末。
- 干扰项是对正确读音做**变形**，不是另找一个别的词。常用的几种变形：长音有无（きょう/きょ、こう/こ、えい/え）、清浊（か/が、は/ば/ぱ）、促音有无（っ）、拨音有无（ん），或者把某个汉字换成它的另一个音读。
- 最好的出法是挑**两种变形做 2×2**：正确读音、只做变形 A、只做变形 B、两种都做。比如 敬語：けいご / けご / けいごん / けごん。
- 训读带送假名的词（〜い、〜る），四个选项的送假名部分必须一样，只有汉字的读法不同。
- 每个干扰项都不能是这个汉字词的另一种合法读法。

### 表記（划线的平假名 → 选汉字写法）
- ⚠️ 2026-10-10 对照官方后：干扰项**以形近字为主**，同音字只作补充，见文末第 33 条。
- 干扰项把其中一个或两个字换成**同音字或形近字**，同样最好做 2×2。比如 返信：返信 / 返心 / 変信 / 変心。
- 干扰项尽量是不存在的假词。如果某个干扰项恰好是一个读音相同的真词，句子语境必须能明确排除它，并在解析里说清楚。

### 語形成（只有 N2）
- 考派生词和复合词：句中挖空，填一个接头词或接尾词（不〜/無〜/未〜/非〜、〜性/〜感/〜化/〜的/〜式/〜風），或复合动词的后项。
- 四个选项是同一类语素，只有一个能和前后组成真实存在、意思通的词。

### 文脈規定（句中挖空 → 选词填入）
- 四个选项**词性相同、活用形相同、长度相近**，从语法上看都能填进去，只有一个意思通。
- 干扰项要有迷惑性，常见做法：和正解共用一个汉字（場合/具合/試合 这类）、属于同一个语义场（各种「钱」、各种「移动」）、拟声拟态词用同一种 ABAB 形式、片假名词形状相近。
- ⚠️ 逐个把干扰项代进句子读一遍，只要有一个「也说得通」，就换掉。

### 言い換え類義（划线的词或短语 → 选意思最接近的说法）
- 正确选项可以是更简单的同义词，也可以是一个解释性短语（比如「外で食事をする」这种）。正确选项的难度要比划线词低。
- 四个选项代进句子后**语法都通**，不能靠语法排除，只能靠意思排除。干扰项和正确选项的形式要一致（都是动词的た形、都是名词等等）。

### 用法（给一个词 → 四个句子，选用法正确的那一个）
- 四个句子都用到这个词，而且除了这个词之外，句子本身都是自然的日语。
- 三个错句错在「这个词放在这里不对」，换成某个近义词或易混词就对了。错误要明显到母语者一眼就能看出来，不能只是「稍微有点不自然」。
- 在解析里写出每个错句应该换成哪个词。

### 文法形式の判断（句中挖空 → 选语法形式）
- 句子可以是一句话，也可以是 A「…」B「…」的对话。
- 四个选项接续方式相同，表面上都能接上，只有一个在意思或语用上成立。干扰项从本级和低一级的语法里挑。
- 这种题最容易出现两个都对的情况，要逐个代入检查。

### 文の組み立て（★ 排序）
- 句子里挖四个空，标一个 ★（多数放在第 3 个空，也可以放在第 2 或第 4 个），选项是打乱的四个词块，问 ★ 位置应该填哪一块。
- 词块按「文节」来切，比如「東京を」「はじめとする」「全国の都市で」「上映される」这样，不要把一个词从中间切断。
- ⚠️ **只能有一种自然的顺序**。写完后把四块的其它排列都想一遍，只要有第二种也能说的顺序，就重新切块。
- 在 `order` 字段里写出正确顺序。

### 文章の文法（一篇短文，几个空）
- 写一篇原创短文，篇幅大致是 N5 150–250 字、N4 250–350 字、N3 300–450 字、N2 450–600 字、N1 550–750 字。题材贴近生活（留学生写的感想、学校或公司通知、随笔都可以），N2、N1 可以写成评论或说明文。
- 空里考的是接续词、指示词、文末表现、语法形式，还有前后文的呼应关系。四个选项都是短语。

⚠️ **2026-10-10 普查结论：文章题是整套题里最差的一块**（卷 1–4 各级都有）。真题的文章题考的是读懂全篇，
不是把四道单句题拼成一段话。下面每一条都要做到：

- **整篇连贯，先写文章再挖空。** 先写一篇不挖空也站得住的短文，通读一遍，确认没有下面这些毛病，再决定挖哪里：
  - 前后事实矛盾：开头说「借来展出」，结尾成了「希望继续捐赠」；店员先说「不知道原因」，下一句就说出了原因。
  - 凭空出现的人、物、指代：「この本の交換会」前文没有提过交换会；「野菜や肉」前文只有蔬菜；「改修後」前文没提改修；
    「友達は…」之前没交代朋友是谁。新出现的人、物第一次出现时要先交代，「この／その」必须有前文可指。
  - 时间顺序乱：「我第一次去」，后面却讲「上个月大家读了什么」；先讲巡回展出，再回头讲资料保存状况。
  - 开了头不收：「母亲也想去」之后母亲再也没出现；结尾突然转到一件和主线无关的事（生日文章结尾变成母亲叫妹妹洗碗）。
  - 结尾和前文对不上：「最后想自己修好」，可是全文作者一次也没自己修过。
- **至少一半的空要依赖别的句子才能做。** 写完逐个检查：只读空所在的那一句，能不能选出答案？能的话，这个空就是单句题。
  依赖上下文的写法：接续词放在两句之间（そこで / それでも / たとえば），指示词回指前文（その本），
  文末表现要靠前文的时间或说话人身份才能定。在 `explanation` 里写明「要看哪一句才能选」。
  纯形式空（な形容词接续、助词）一篇最多一个。
- **题材分散。** 卷 1–4 的文章里，图书馆 / 读书会 / 社区活动 / 料理会占了一大半，而且几乎都是第一人称流水账。
  这些题材**不再用**。可以写：通知、邮件、留言、店铺或设施的说明、给朋友的信、对某件事的看法（N3 以上）、
  评论或说明文（N2、N1）、工作或打工中的一件事、搬家、生病、问路、天气对计划的影响等。同一份题里的几篇文章题材、文体都要不同。
- **难度贴级。** N1 文章写成 N2 难度是普查发现的问题之一：N1、N2 要有抽象议论、让步、转折层层推进，词汇用本级的。
- **正解不能为考点硬塞。** 「〜理由もよく分かるわけだ」（应为「分かった」）、「〜ためには…知らせてしかるべきだ」这种
  为了用上某个语法而写出来的不自然句子，宁可换考点。
- 文章写完后，**正解代回原文通读一遍**；选项不能和文章里已有的词重复（文章写了「雨の日が続いた」，选项又从「雨の日が続いた」开始）。

## 通用质量线（每题都要过）

1. **唯一正解**：每个干扰项都要写一句它为什么错。写不出来，或者它只是「不太自然但能说」，就换掉。
2. **不能靠形式排除**：选项的长度、词性、活用形、送假名都要一致；任何一个选项都不能因为语法接不上而被一眼排除（考的就是语法的题除外）。
3. **语境能锁定答案**：表記题和文脈規定题尤其注意，句子里要有能确定答案的线索。
4. **自然的日语**：写母语者真的会说的句子，不要教材腔，也不要中文式日语。
5. 同一个考点不出两次；话题分散一点（工作、学校、家庭、天气、健康、购物、交通等）。
6. 正解位置不用管：审校前和导入时都会统一打乱选项顺序（以前要求「均匀」，结果写成了 1234 循环）。别为了凑位置去调换选项。
7. **题干长度贴近真题**：通常只有一句，N5、N4 大约 10–25 字，N3 大约 20–40 字，N2、N1 可以长一些。
   不要为了保证唯一正解而多写一句说明、把答案解释出来，那样题目会比真题容易得多。要靠选对干扰项来保证唯一正解。
8. 读音题的干扰项要像一个可能的读音，不要拼出日语里几乎不出现的形式（比如词尾的「っく」）。
9. 考点挑真题会考的常见词，不挑冷僻词。
10. `explanation` 和 `distractors` 一律用中文写。
11. 排序题要有固定的前后文，四块只填句子中间的一段，不能整句只有四个空。
12. 比较句、没有主语的句子、近义语法（〜ておく / 〜てみる、〜はずだ / 〜かもしれない）最容易多解，题干里要有锁定答案的线索。
13. 排序题：把所有合理的排法都想一遍，★ 位置的答案只能有一个。
14. 文章题的空号按在文章里出现的先后编号。
15. 排序题的 ★ 不要放在一定排在最后的谓语上（「います」「食べます」「触れてはならない」这种），那等于白送；★ 放在要靠语法关系才能定位的那一块。
16. 排序题题干里已经给出的词，不要再出现在选项里（题干末尾写了「ですか」，选项就不能再有「ですか」）。
17. 文法题、文脈題的题干必须真的有一处（　　）空，不能把正解直接写进题干。
18. 用法题的三个错句要错在「意思用错了」（该用近义词的地方用了它），不要写成谁都看得出来的胡话（「医師から機能をもらった」）；也不要只是同音不同字的写法问题（「温かい / 暖かい」）。
19. 不要用中文式的被动句（「母に作られた弁当」应说「母が作ってくれた弁当」）；读不顺的句子，母语者不会那样说，就换说法。
20. 读音题的干扰项按「两种变形做 2×2」来出，变形之后仍要像日语里会出现的读音（「せつぴ」「せっび」这种拼法不要）。
21. 排序题的四块是**短词块**（一个词或一个助词短语，像「実情に」「即して」「という」「の」），不要写成四个整句步骤再靠「最初に／次に／まず」定先后——那考的是事情顺序，不是语法。
22. 文章题和同一份题里的其他题不要撞场景：文章写了「雨の日も開きます」，文法题就别再考「雨（でも）開きます」。文章前后也不能自相矛盾（开头说「每月帮孩子读书」，后面又说「下个月开始给孩子读书」）。
23. 说话人的身份要配得上语气：「〜ものではない」是长辈训人，店员不会这样对客人说。

### 2026-10-10 普查后补的几条（sol 逐题普查卷 1–4 全部 981 题，Claude 二审）

24. **正解代回题干，整句读一遍。** 普查查出的硬伤大多是拼接错：题干带「に」、正解是「にかこつけて」，代入后成了「ににかこつけて」；
    题干空后有「ました」、选项也带「ました」，代入后成了「謝りましたました」；「私が担当（こと）になった」漏了「する」。
25. **`explanation` 和 `distractors` 里不许出现选项编号或位置。** 不写「第三句」「最后一句」「选项2」「顺序为[3,4,1,2]」，
    直接引用选项原文（「『授業に間に合いました』是正确用法」）。原因：审校前和导入时选项会被打乱，打乱的脚本会改 `order`
    和 `distractors` 的键，**但不会改解析正文**，写了编号就会指错。卷 1–3 因此有 11 题解析指错。
26. **四个选项只差时态（或只差肯定 / 否定）时，题干必须有锁定时态的词**（今、昨日、毎日、これからは）。
    「冬の山は雪が多く、外はとても（寒い）」里「寒かった」同样自然；「病院では…撮って（はいけません）」里「はいけませんでした」也说得通。
27. **解析不许添加题干里没有的事实。** 普查见过：题干只说「船早上出发」，解析写成「回程的船第二天早上才开」；
    题干没有旅行，解析写「旅行要用轻包」；原文没有母亲，解析写「母亲」。干扰项为什么错，要用题干里有的内容来说明。
28. **词汇题的句框不能比被测词难。** N5 考「覚える」，句子却用「〜ようにしています」；考「困る」，句子用「帰れず」。
    句框用本级以下的语法，难度留给考点。
29. **同一个场景不要在几套题里反复出现。** 「字が大きい本、子どもでも読める」在卷 1、卷 3 的 N4 文法里各出现一次。
    出题前看一眼前几套同科目的题干（`~/Documents/shushugo-wt/_codex/jlpt-trial/set*/<本级>-<科目>/questions.json`，卷 1 在 `jlpt-trial/<本级>-<科目>/`，只读；考点已经自动去重，场景还没有）。
30. **第二正解的判据**：干扰项代进去，**母语者在真考场上会不会认为也对**。会，就换掉。
    反过来，只有补出一段特殊背景才说得通的读法（「药店也可能卖邮票」「同一天入职的也可能是上司」）不算第二正解，不用为它改题。
    审校时同样按这个标准报，不要靠逻辑上的「不能排除」凑第二正解。
31. 用法题的错句复查一遍：三个错句应当各自对应一个**真实的易混词**（見つける / 見つかる，都合 / 具合，貸す / 借りる），
    而不是把这个词用在荒谬的对象上（「この道は下手」「去旅館借书」）。三个错句也不要都是同一种错法。

### 2026-10-10 对照 JLPT 官方样题后补的几条（官方 2018 年版公式问题集 N1–N5，Claude 逐题读后对照）

对照结论全文：`docs/jlpt-authoring/official-comparison-1010.md`（仓库 jlpt/sets 分支）。考点级别、题型配比、题材都合适，**偏的是考法**：

32. **漢字読み：每套约一半用「真词干扰」**。官方约一半读音题考的是「这个汉字是哪个词」：考点用训读词或常用和语，
    三个干扰项是**同一语义场、读音长度相近的真词**（例：考「味」配 かたち／いろ／におい／あじ；考「払って」配 くばって／はらって／かざって／ひろって）。
    另一半才用长音、清浊、促音、拨音的变形（2×2）。音读汉语词仍用变形；训读词优先用真词干扰。
33. **表記：干扰项以形近字为主**（計画／訂画／計書／訂書、貸して／貨して／資して／質して、輸出／諭出／輪出／論出），
    单字词可用同一语义场的字（白い／黒い／赤い／青い、池／湖／港／波）；同音字拼凑（「電死レンジ」「進文」）对中文母语考生没有区分度，最多一题一个。
34. **用法：三个错句 = 三个不同的近义词位置**。每个错句是「把考点词放到某个具体近义词该用的地方」，母语者一眼能看出该换成哪个词：
    さいきん（误当 もうすぐ／さっき）、沸騰（误当 気温が上がる）、出張（误当 旅行／出勤／参加）、延長（误当 延期）、閑静（误当 安静／暇）。
    荒谬替换（「駅への行き方を触りました」「授業が直りました」）一律不要。说明里写「应说『X』」。
35. **文法形式：题型要混合**。每套里除了「四个语法点辨义」，还要有：
    - 会话体，带场景标签（（靴屋で）（電話で）（お知らせで）），N5/N4 约占一半，N3 约三分之一，N2/N1 至少 2 道；
    - 敬语（N4 起；N3–N1 每套至少 1 道：お待ちください、申します、お越しになりました、おいでになり、させてもらおうかと思って）；
    - **同一个词或句型的不同形式**做四个选项，考接续（あきらめ／あきらめて／あきらめる／あきらめた ＋かける；次第には／次第に／次第では／次第；知っていても／知られては），每套至少 2 道；
    - 副词、接续词（まだ／また、なかなか、もうすぐ、そのうち、もっとも），每套 1–2 道。
    N1/N2 不要只从传统「機能語清单」挑冷门句型：官方 N1 十道里清单型约四道，其余靠接续、敬语、语境、视点。
36. **文章の文法：空格考篇章，不考本级语法点**。官方的空是接续词（でも／しかし／けれども）、指示词（これ／それら／そういう）、
    视点与授受（言ってもらいました／言ってしまいました、教えてもらいました）、文末语气（ご存じだろうか、のかもしれません、に違いない）、受身（使用されている）。
    每篇至少一半的空属于这几类，且必须看前后句才能选。题材：N5–N3 留学生作文或身边的事，N2 杂志专栏、说明文，N1 随笔或评论（带作者观点）。

## 输出格式：`questions.json`

一个数组，每题一个对象：

```json
{
  "level": "N3", "section": "文字・語彙", "mondai": 1, "kind": "漢字読み", "no": 1,
  "stem": "職場では、相手に合わせて[[敬語]]を使います。",
  "options": ["けいご", "けご", "けいごん", "けごん"],
  "answer": 1,
  "target": { "type": "word", "id": 1234, "surface": "敬語" },
  "explanation": "敬語读けいご（长音）。",
  "distractors": { "2": "少了长音い", "3": "多了拨音ん", "4": "长音和拨音都错" },
  "order": null,
  "doubt": null
}
```

- `no` 是本科目内的连续编号，从 1 开始。`mondai` 是本科目内的大题号，照「本次任务」表里的顺序。
- 划线部分写成 `[[…]]`，挖空写成 `（　　）`。排序题的四个空写成 `＿＿ ＿＿ ★ ＿＿`（★ 放在哪个空就写在哪个位置），并在 `order` 里按正确顺序写出选项编号，比如 `[3,1,4,2]`。
- 文章题：第一题加一个 `passage` 字段放全文，空用这几道题的 `no` 编号写成 `[n]`；每道文章题的 `stem` 就写 `"[n]"`。
- `doubt`：自查后仍然拿不准的题，写一句为什么拿不准；拿得准就写 `null`。
