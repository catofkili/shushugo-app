## 0. 背景一句话

收集日（ShuShuGo）是一个面向中文母语者的日语背单词 App。现在要加一个「五十音」入门库：
把假名、发音规则、入门短语做成卡片，配一份可点开的术语解释。风格对标《新标准日本语 初级》入门单元。

## 2. 卡片 JSON 格式（文件 A）

```json
{
  "version": 1,
  "cards": [
    {
      "id": "hira-shi",
      "kind": "kana",
      "group": "seion",
      "front": "し",
      "romaji": "shi",
      "pair": "シ",
      "origin": "之",
      "note": "舌尖平放不卷，接近「西」不是「诗」。さ行整行不卷舌，す 也接近 si",
      "examples": [["しお", "盐"], ["あし", "脚"], ["わたし", "我"]]
    }
  ]
}
```

字段说明：

| 字段 | 必填 | 说明 |
|---|---|---|
| `id` | ✓ | 英文小写 + 连字符，全局唯一。字卡 `hira-<romaji>` / `kata-<romaji>`，规则卡 `rule-<slug>`，短语卡 `phrase-<slug>` |
| `kind` | ✓ | `kana` / `rule` / `phrase` |
| `group` | ✓ | 见第 3 节的分组名 |
| `front` | ✓ | 正面显示的文字 |
| `romaji` | kana / phrase 必填 | Hepburn 罗马字（shi / chi / tsu / fu / ji / zu），**不用训令式**（si / ti / tu / hu） |
| `pair` | kana 必填 | 平假名卡填对应片假名，片假名卡填对应平假名 |
| `origin` | kana 必填 | 字源汉字，一个字。平假名是万叶假名草书来源，片假名是取的偏旁来源。见第 3.5 节 |
| `note` | ✓ | 说明文字，**60 字以内**。字卡按「行」写同一段（あ行 5 张卡 note 相同），见第 3.6 节 |
| `examples` | ✓ | `[[假名, 中文], ...]`，字卡 3 个、规则卡 4 个、短语卡 0 个（填 `[]`） |
| `quiz` | rule 必填 | `[[正确拼写, 错误拼写], ...]`，至少 3 组。正确拼写必须是词表里的词 |
| `meaning` | phrase 必填 | 中文意思 |
| `scenes` | phrase 必填 | 3 句使用场景，每句 20 字以内 |

## 3. 卡片清单（数量要精确对上）

### 3.1 `seion` 清音 —— 92 张

平假名 46：あいうえお かきくけこ さしすせそ たちつてと なにぬねの はひふへほ まみむめも やゆよ らりるれろ わを ん
片假名 46：对应的 ア〜ン。

- **不收** ゐ ゑ ヰ ヱ。
- を / ヲ 的 note 写明「现代日语只做助词 wo，词里不出现」，romaji 填 `wo`。
- ん / ン 的 note 写明「单独一拍，不能开头」。

### 3.2 `dakuon` 浊音・半浊音 —— 50 张

平假名 25：がぎぐげご ざじずぜぞ だぢづでど ばびぶべぼ ぱぴぷぺぽ。片假名 25 对应。

- ぢ romaji `ji`、づ romaji `zu`，note 写明「和 じ／ず 同音，只在 ちぢむ・つづく・はなぢ 这类词里出现，打字打 di / du」。
- `origin` 填清音那张的字源（が 填 加）。

### 3.3 `youon` 拗音 —— 66 张

11 行 × 3：きゃきゅきょ しゃしゅしょ ちゃちゅちょ にゃにゅにょ ひゃひゅひょ みゃみゅみょ りゃりゅりょ ぎゃぎゅぎょ じゃじゅじょ びゃびゅびょ ぴゃぴゅぴょ。片假名 33 对应。

- **不收** ぢゃぢゅぢょ。
- romaji：しゃ sha、しゅ shu、しょ sho、ちゃ cha、じゃ ja、じゅ ju、じょ jo，其余按 kya / gyu 规律。
- `origin` 填大假名那张的字源。
- note 写「一拍」和「小 ゃ 写在右下角、比正常字小一半」。

### 3.4 `gairai` 外来语专用片假名 —— 10 张

### 3.6 发音说明（`note`）—— 按行写，一行一段，同行各卡复用

要求：说给**中文母语者**听，用汉语拼音 / 汉字做参照，60 字以内，不出现国际音标。
每行必须点出「中国人最容易读错的那一点」。下面是必须覆盖的要点，措辞自定：

| 行 | 必须说到 |
|---|---|
| あ行 | あ 口型比汉语 a 小；**う 不圆唇**，嘴不往前突；え 在「爱」和「诶」之间；お 比汉语 o 口小 |
| か行 | 词首送气像 k，**词中不送气听着像拼音 g，但仍是 か** |
| さ行 | 全行不卷舌；し 接近「西」不是「诗」；す 接近 si 不是 su（嘴不圆） |
| た行 | 词中不送气像拼音 d；ち 接近「七」；**つ 是拼音 c 的音，不是 ts 拼读** |
| な行 | 接近拼音 n；に 接近「尼」 |
| は行 | は 接近「哈」；**ふ 是双唇吹气，不是拼音 f（不咬唇）**；へ 接近「嘿」 |
| ま行 | 接近拼音 m |
| や行 | 接近拼音 y；ゆ 接近「yu」但嘴不那么圆 |
| ら行 | **舌尖轻弹一下，介于 l 和 r 之间，不卷舌、不颤** |
| わ行 | わ 接近「哇」但嘴不那么圆；を 只做助词 |
| ん | 单独一拍；后面是 m/b/p 时读 m，n/t/d 时读 n，k/g 时读 ng，词尾轻鼻音 |
| 浊音 | **一开口声带就振动，是真浊音**；和词中不送气的 か／た 不是一回事 |
| 半浊音 | ぱ行 = 拼音 p 的不送气版，接近拼音 b |
| 拗音 | 大假名 + 小 ゃゅょ 合成一拍；大小是区别 |
| 外来语专用 | 只用于外来语，本土词没有这个音；有的老词用旧拼法（チケット vs パーティー） |

### 3.7 `rule` 规则卡 —— 12 张

正面是一个问题或一个片段，反面是规则 + 4 个例词 + 拼写二选一题。`quiz` 里的正确项必须是词表里的词，
错误项是把长音 / 促音 / 拗音去掉或写错的形态。

| id | front | 规则要点 | 例词方向 |
|---|---|---|---|
| `rule-long-a` | `ああ` 读什么？ | あ段 + あ 拉长一拍 | おかあさん おばあさん |
| `rule-long-i` | `いい` 读什么？ | い段 + い | おにいさん おいしい ちいさい |
| `rule-long-u` | `うう` 读什么？ | う段 + う | くうこう ぎゅうにゅう ゆうべ しゅうかん |
| `rule-long-e` | `えい` 读什么？ | え段 + い 读 ee 不读 e-i；おねえさん 是例外写 ええ | せんせい えいが とけい きれい |
| `rule-long-o` | `おう` 读什么？ | お段 + う 读 oo；おおきい とおい 这几个写 おお | おとうさん がっこう おおきい とおい |
| `rule-long-bar` | `ー` 是什么？ | 片假名长音符，把前一个音拉长一拍 | ケーキ コーヒー ノート スーパー |
| `rule-sokuon` | 小 `っ` 是什么？ | 促音，占一拍停顿，后面清音更用力；不能开头、不能结尾 | きって ざっし きっぷ がっこう |
| `rule-hatsuon` | `ん` 后面跟什么会变？ | 见 3.6 ん 那行 | さんぽ えんぴつ にほんご ほん |
| `rule-youon-long` | `きょう` 几拍？ | 拗音一拍 + 长音一拍 = 两拍 | きょう りょこう じゅう ちゅうごく |
| `rule-unaspirated` | `たかい` 的 か 为什么像 ga？ | 词中清音不送气，仍是清音 | たかい あなた いくつ みかん |
| `rule-particles` | `は` 什么时候读 wa？ | 做助词时 は 读 wa、へ 读 e；词里照常 | わたしは とうきょうへ こんにちは |
| `rule-pitch` | 声调是什么？ | 平板 / 头高 / 中高 / 尾高，高低不是轻重；**只说明，`quiz` 填 `[]`** | はし（桥／筷子） あめ（雨／糖） |

`rule-particles` 的例词是短语，允许不在词表里，校验脚本对这张卡放行。

### 3.8 `phrase` 短语卡 —— 20 张

おはようございます こんにちは こんばんは おやすみなさい さようなら ありがとうございます どうもありがとう
すみません ごめんなさい はじめまして どうぞよろしくおねがいします いただきます ごちそうさまでした
いってきます いってらっしゃい ただいま おかえりなさい おつかれさまでした しつれいします おげんきですか

- `romaji` 按 Hepburn，长音写成双写（ohayou → `ohayou` 不写 ohayō，不加长音符）。
- `note` 写拍数分解，例：「す·み·ま·せ·ん 5 拍，ん 单独一拍」。
- `scenes` 3 句：什么时候说、对谁说、有什么容易用错的地方。
  例（すみません）：撞到人 → 道歉；叫店员、问路开口 → 「劳驾」；别人帮了忙 → 比 ありがとう 更客气的谢。

## 4. 形近表（文件 B）

```json
{ "version": 1, "pairs": [["あ","お"], ["め","ぬ"], ["さ","ち"], ["き","さ"], ["ね","れ","わ"], ["は","ほ"], ["る","ろ"], ["い","り"], ["く","へ"], ["シ","ツ"], ["ソ","ン"], ["ク","ワ","フ"], ["コ","ユ"], ["チ","テ"], ["ナ","メ"], ["ヌ","ス"], ["マ","ム"]] }
```

- 一组 2〜3 个，同一个假名只能出现在一组里。
- 上面 17 组是起点，可以增删，但每一组必须是**真的容易看混**，不许凑数。
- 只用来生成选择题的干扰项，不是卡片，不需要解释文字。

## 5. 术语表（文件 C）

```json
{
  "version": 1,
  "terms": [
    {
      "label": "浊音",
      "title": "浊音",
      "body": "が ざ だ ば 四行。在清音右上角加两点「゛」，发音时一开口声带就振动。",
      "examples": ["か→が", "さ→ざ", "た→だ"]
    }
  ]
}
```

必须覆盖的术语（35 条，可多不可少）：

| 组 | 术语 |
|---|---|
| 假名 | 平假名 · 片假名 · 五十音 · 清音 · 浊音 · 半浊音 · 拗音 · 外来语 · 外来语专用音 |
| 拍 | 拍 · 一拍 · 长音 · 长音符 · 促音 · 拨音 · 小写假名 |
| 发音 | 送气 · 不送气 · 声带振动 · 卷舌 · 双唇音 · 闪音 · 鼻音 · 圆唇 |
| 声调 | 声调 · 平板型 · 头高型 · 中高型 · 尾高型 |
| 字源 | 字源 · 草书 · 万叶假名 · 偏旁 |
| 书写 | 送假名 · 罗马字 |

要求：

- `body` 两句话、60 字以内、**大白话**。这段文字本身会被拿去识别术语再弹一层，
  所以 body 里尽量只让一个别的术语露头（「拗音 = 大假名 + 小假名合成**一拍**」可以，一句里塞四个术语不行）。
- `examples` 2〜3 个，短。
- `label` 是正文里要被识别的原文，`title` 是弹窗标题，通常相同。同义写法（「拨音」「撥音」）各建一条，title 相同。
- 术语必须真的在文件 A 的 note / 规则里出现过至少一次（脚本会查）。出现在卡片里而术语表没有的「高深词」也算错——
  判据：一个没学过日语的中国人看到这个词会不会停下来想「这是什么」。会，就建条目。

## 6. 文字风格

- 全部简体中文，日文原文用假名，不用罗马字代替假名。
- 引号用「」，不用 “”。
- 参照物永远是汉语拼音和常见汉字（「接近『西』」），不用英文、不用国际音标。
- 短句。一个 note 最多两句。
- 不写「注意」「请记住」「重要」这类提示词，直接说事实。

## 7. 校验脚本（文件 D）`frontend/scripts/verify-kana-cards.mjs`

Node ESM，`node frontend/scripts/verify-kana-cards.mjs` 零参数运行，全部通过 exit 0 并打印一行 `kana cards ok: N cards`，
任何一条不过 exit 1 并逐条打印「哪张卡、哪个字段、为什么」。不许引入新依赖（`node:fs` / `node:path` 就够；
词表读 `docs/kana-cards-words.tsv`，不读数据库）。

必查项：

1. 三个 JSON 能解析，`version` 都是 1。
2. 卡片数：`seion` 92、`dakuon` 50、`youon` 66、`gairai` 10、`rule` 12、`phrase` 20，合计 250。
3. `id` 全局唯一，符合命名规则。
4. 每张 `kana` 卡：`front` 一到两个假名字符；`romaji` 非空且全小写字母；`pair` 平↔片互相对得上
   （拿 `hira-x` 的 `pair` 去找 `kata-x` 的 `front`，必须一致）；`origin` 在第 3.5 节表内。
5. 每张卡 `note` ≤ 60 字。
6. `examples` 数量：kana 3、rule 4、phrase 0；每个例词的假名在词表第 2 列里存在
   （`gairai` 组另加 3.4 白名单；`rule-particles` 放行；`rule-pitch` 放行）。
7. `rule` 卡 `quiz` ≥ 3 组（`rule-pitch` 例外为空），每组正确项在词表里、错误项不在词表里、两项不相等。
8. 形近表：每个假名只出现一次，每组 2〜3 个，全是单个假名字符。
9. 术语表：`label` 唯一；每个 `label` 至少在某张卡的 `note` / `quiz` / `scenes` 里出现一次。
10. 反查：把所有卡片文字合起来，对着第 5 节那张术语清单逐个查，清单里的词在正文里出现了但术语表没有 → 报错。

脚本本身要有一个自检：在文件末尾用一段内联的坏数据（少一张卡、一个不存在的例词）跑一遍校验函数，
断言它返回了错误。不用测试框架。

### ⚠️ ① 例词必须**含有**这张卡教的假名 —— 第一版 118/218 张不含

原要求只写了「例词必须来自词表」，校验脚本就只查了「在不在表里」。
而当时给的表是 892 个 **N5** 词、其中片假名词只有 **80 个**，而片假名卡有 104 张、需要 312 个例词槽。
凑不出来，于是拿**同一行的近似词**顶上，全都合法通过：

```
ネ 卡  → ねこ・あね・かね          （全是平假名 ね）
ヅ 卡  → シャツ・スポーツ・ワイシャツ （全是 ツ）
ぴ 卡  → いっぱい・きっぷ          （ぱ 和 ぷ，就是没有 ぴ）
フェ 卡 → カフェ・フェリー・フォーク   （第三个是 フォ）
```

**卡片的正事就是例词**，这等于整批内容说了一半。现在：

- 词表换成 **`docs/kana-cards-words.tsv`**（出厂词典里全部纯假名词 9,840 个，**任意等级**，
  由 `SELECT kana, meaning, jlpt_level FROM words WHERE kana 全是假名` 导出）。
- 校验脚本的 `containsFront()` 是这一条的闸，**任何时候都不许放宽**。
- 清音 / 浊音卡要**排掉「假名后面跟小 ゃゅょ」那种命中**：きゃく 里的 き 读 kya 不是 ki，
  拿它教 き 是错的。

### ⚠️ ② 例词数量是 0〜3，不是硬性 3

ヲ・ヂ・ヅ・みゅ・キョ・ニャ・ニョ・ヒャ・ミョ・リャ・リョ・ビャ・ビョ・ピャ・ピョ
这 15 个现代日语里真的没有词。**硬凑 3 个就只能回到 ① 那个毛病。**
现在的分布：3 个 187 张 / 2 个 8 张 / 1 个 8 张 / 0 个 15 张。

**一个例词都没有的卡，note 必须说明「几乎不出现在词里」**，校验脚本查这一条 ——
否则用户看到的是一张空卡，分不清是没有词还是数据坏了。

### ⚠️ ③ 人工补的例词单独成段（`MANUAL_WORDS`，26 个）

出厂词典里没有、但都是基础词汇：こんにゃく・さんびゃく・はっぴゃく・チューリップ・
ギョーザ・ミャンマー・ヒョウ・リゾート……**这是整批内容里唯一没有机器依据的部分**，
所以它独立摆在校验脚本顶上一段，让人一眼看完复核。改这份名单等于改内容。

### ⚠️ ④ note 说的必须是**这张卡自己**的那个音

原要求写「字卡按行写同一段，同行各卡 note 相同」，而 note 里又举了具体的音，于是：

```
ひゅ 卡 → 「ひゃ 是 ひ 和 ya 快速连读」   （在讲 ひゃ）
ニョ 卡 → 「にゃ 像「你呀」连读成一拍」   （在讲 にゃ，还是平假名）
ネ  卡 → 「に 接近「尼」」               （片假名卡写平假名）
フェ 卡 → 「老词不用 ティ，写成 チ」       （十张外来语卡共用一段，那段在讲 ティ）
```

现在：拗音 note 里的音跟着本卡换、**片假名卡的 note 一律用片假名**
（`ヒ 加小 ュ 合成一拍`）、外来语专用音十张各写各的。
⚠️ 片假名卡转写时要小心 note 里的**平假名词**（だ行原来举了 ちぢむ・つづく），
转成片假名就成了 チヂム —— 那三张（ダ・デ・ド）单独写了 note。

### ⚠️ ⑤ ぢ/づ 的 romaji 是 **ji / zu**，id 破例叫 `hira-di`

原要求同时写了「ぢ romaji 填 ji」和「id = `hira-<romaji>`」，而 `hira-ji` 已经被 じ 占了。
第一版选择改 romaji 保 id，写成 `di`/`du` —— **romaji 是答案面**，那等于教「ぢ 读 di」。
现在 romaji 是 ji/zu，id 保留 di/du（id 只是键，不给用户看）。

### ⚠️ ⑥ quiz 的错误项不能是**全词典**里的另一个词

第一版按 N5 表查的，换成全词典之后有 4 组当场露馅：

「拼写二选一」里两个都是真词的话，题目本身是错的。已各换一组。
