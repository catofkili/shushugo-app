# 背词页陪伴水豚（2026-10-14 立项）

> 作者原话（10-14）：「背单词页面也要加一只水豚，这只水豚可能要不一样的格式更高标准什么的，因为它是见到时间最长的那个，
> 我打算之后卖的装扮围绕它，和答题情况交互，不要出现频繁的文字，就开头、正确率明显低、连胜连负和快要结尾的时候说说话，
> 然后这个水豚本身可点击，再加少量和倒计时相关比方说时间过半之类的少量文字提示吧，本身也可以点击水豚得到至少五种交互，
> 但如果会导致太吃配置什么的，可以留到后面做。」
>
> 上位规则：`docs/FRONTEND_V3_PLAN.md`（一屏一个主角、不用 emoji、动效 token、基础样式 = 终态）。

## 1. 它是谁、为什么要更高标准

- 背词页是用户每天待得最久的一屏，这只水豚是全 App 被看得最久的角色。**以后柚子商店卖的装扮（帽子、围巾、手持物）都穿在它身上**。
- 所以它不能用现成的 `mood-*` 贴纸凑：那批图每张构图、大小、朝向都不一样，换表情时整只会跳。它要一套**专门画的帧**（§4）：
  同一个姿势、同一块画布、头和身体的位置在每一帧里都一样，只换表情和手。这样换帧不跳，装扮也能按固定锚点叠上去。
- 帧到之前，先用现成 `mood-*` 贴纸顶着把行为做对（§4.3 的对照表），画到了只换图、不改逻辑。

## 2. 放在哪

- 题卡**右下角，骑在底部操作区（「显示答案」/ 评分按钮）的上沿**，一半压在答案面板角上。翻面前后位置不变。
  高 72px（网页 / 小程序同一个数）。单词卡、混合学习的语法 / 汉字 / 辨析卡都在；完成页、休息页、空状态不出现（那些页有自己的吉祥物）。
- **一屏一只**：顶栏小路上那只走路的小水豚换成一个非角色的标记（小柚子），小路起点的 🧠 emoji 一并去掉（v3 不用 emoji）。
- 设置里加一个开关「背词页陪伴水豚」，默认开。关了就整个不渲染（不是隐藏）。
- 不挡任何可点的东西：它自己是一个按钮，其余区域 `pointer-events: none`；评分按钮的点击热区不能被它盖住（必要时按钮区右侧留出它的位置）。

## 3. 行为

### 3.1 对答题的反应（无文字，每题都有）
| 事件 | 帧 | 动作 |
|---|---|---|
| 答对 | happy | 小跳一下（translateY -6px + 压扁回弹，`--ds-ease-spring`，320ms），回 idle |
| 连对 5 / 10 / 20 | cheer | 跳两下 + 身后一圈光（CSS），停 1.2s |
| 答错 | worried | 缩一下（scale .94）+ 轻摇头，停 900ms |
| 连错 ≥ 3 | sad | 持续到下一次答对 |
| 翻面（显示答案） | think | 歪头看向卡片，300ms |
| 60 秒没任何操作 | sleepy | 打盹（呼吸变慢）；下一次操作惊醒（surprised 300ms → idle） |

idle：轻微呼吸（scale 1 → 1.02，3.6s 循环）+ 每 4–7 秒随机眨一次眼（blink 帧 120ms）。减少动效时：不呼吸、不眨眼，只换帧不做位移。

### 3.2 说话（气泡，很少）
总规则：**一次学习最多 6 句**；两句之间至少隔 20 秒；气泡显示 2.4 秒自己收起，点一下也收；**作答反馈在播时不说**。
文案就是下面这些，不要另加（UI 文案纪律：短、不解释机制）。

| 时机 | 判据 | 文案（随机其一） |
|---|---|---|
| 开头 | 本次进背词页的第一张卡 | 「今天也一起。」/「来了来了。」 |
| 正确率明显低 | 已答 ≥ 10 且最近 10 题对 < 5；一次学习只说一次 | 「慢一点也没关系。」/「这批有点难，稳住。」 |
| 连对 | 连对 10、20 时 | 「十连对！」/「二十连对，厉害。」 |
| 连错 | 连错 3 时（同一段连错只说一次） | 「这几个难缠，标个收藏？」/「没事，下一个。」 |
| 快结束 | 今日计划剩 ≤ 5 时（只说一次） | 「还剩最后几个。」 |
| 倒计时过半 | 倒计时学习开着，本段 10 分钟过了一半 | 「过半了。」 |
| 倒计时最后一分钟 | 本段剩 60 秒 | 「最后一分钟。」 |

### 3.3 点它（至少五种，不出字）
每次点随机挑一种，**不和上一次重复**：
1. **蹦**：原地跳一下 + 一声吱（`playStreakChirp`）。
2. **转圈**：原地转一圈（rotateY 360，520ms）。
3. **害羞**：shy 帧捂脸 + 两颊红晕（CSS 两个半透明粉色圆），900ms。
4. **挥手**：wave 帧，700ms。
5. **吃柚子**：eat 帧，嘴边掉两粒碎屑（CSS 小圆点下落），1s。
6. **连点 5 下（2 秒内）**：dizzy 帧 + 头顶三颗星绕圈（CSS），2s 后恢复。这一种优先于上面的随机。
点它是一次普通交互，照 `lib/study-clock.ts` 的口径续学习时长（和看例句、开气泡一样，见 `interface-and-design-system.md`「学习时长」一节），不另做排除——判据是「距上次交互多久」，点几下水豚撑不出几秒。

## 4. 画（更高标准）

### 4.1 规格
- 画布 **768×768 透明 PNG**，水豚 3/4 侧坐、面朝左（看向题卡），占画布高约 80%，**所有帧脚底、头顶、身体轮廓位置完全一致**，只改表情 / 手 / 小道具。
- 先画 `buddy-idle`，其余帧都用它当底图**改图**（image edit），不重新生成整只——否则必然跳。
- 画风同 `frontend/public/brand/sheet/` 原图：奶油暖色、深棕圆头描边、柔和扁平。**无文字**。
- 交付时附 `buddy-anchors.json`：每帧的头顶中心、脖子中心、右手位置（像素坐标）——装扮按它对齐。所有帧的头顶 / 脖子坐标应相同（容差 ±4px）。

### 4.2 帧清单（13 张，`frontend/public/brand/buddy/`）
idle、blink（闭眼，其余同 idle）、happy、cheer（举双手）、worried、sad、think（歪头）、sleepy（闭眼耷拉）、surprised、shy（捂脸）、wave、eat（抱着柚子啃）、dizzy（眼睛转圈）。

### 4.3 帧到之前的对照（现成贴纸，小程序主包里都有）
idle→mood-default、blink→mood-default、happy→mood-yay、cheer→mood-cheer、worried→mood-puzzled、sad→mood-puzzled、think→mood-ask、
sleepy→mood-sleep、surprised→mood-surprised、shy→mood-shy、wave→mood-wave、eat→mood-hungry、dizzy→mood-dizzy。
装了别的吉祥物皮肤（柚子商店 mascot 槽位）时，也走这张对照表（皮肤自己的 `mood-*`），直到给皮肤画了 buddy 帧。

## 5. 性能与两端
- 只有一个 `<img>`（小程序 `Image`），换帧 = 换 src；帧图进页就预加载（网页 `new Image()`；小程序本地图无需）。
- 全部 CSS 动画（transform / opacity），不用 JS 逐帧；计时器只有一条（眨眼 / 打盹共用的 setTimeout 链），卸载即清。
- 小程序：帧图进主包（背词页是 Tab 页，不能引用分包私有图）。13 帧 × 72px@2x 预计 ≈ 60–80 KB，主包余量 2026-10-14 约 200 KB。
- 小程序选择器只用 class；不用 `:has()`；减少动效走 `[data-motion="reduced"]`。
