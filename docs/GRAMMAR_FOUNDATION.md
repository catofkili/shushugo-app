# 基础语法框架

> 重建日期：2026-09-14

## 为什么重建

旧版把原因、条件、让步、推测、评价以及 N2/N1 固定表达按语义分成 49 组，再称为“宏观框架”。这种做法只是给既有语法卡换了一种目录，既重复语法辞典，也没有回答词为什么能这样连接、句子为什么能这样变化。

新版只保留能生成或拆解其他句型的底层规则。判断标准是：删掉这条以后，学习者是否会无法解释大量不同句型的共同结构。如果它只解释一个具体表达或一小组近义表达，就应留在 `grammar.ts`，不进入基础框架。

## 内容边界

基础框架目前共 43 条，分为六层。其中 22 条是独立的动词变形课程，不再用一张总表代替教学：

1. 辞书形／基本形
2. 普通形（四种时间／肯否组合）
3. 终止形
4. 连体形
5. ます形
6. ない形（含なかった、なくて、ないで、なければ）
7. て形
8. た形
9. 未然形
10. 连用形
11. ば形／假定形
12. たら形
13. 意志形／意向形
14. 命令形
15. 禁止形
16. 可能形
17. 被动形／受身形
18. 使役形
19. 使役被动形
20. たい形
21. ず／ぬ／ざる
22. まい形

每个词条都必须包含四类动词的构成或适用范围、形式承担的功能、常见接续、例外、易错点和代表性语法卡入口。总表只作索引和横向对照，不能作为这些词条的替代品。

| 层次 | 回答的问题 |
|---|---|
| 句子与谓语 | 谓语为什么在句末；四类谓语如何结句；时间、肯否、文体如何组合；省略和疑问词如何还原 |
| 词类与活用 | 哪些词会变化；22 种动词形式各自怎样构成和使用；形容词和名词谓语如何变化；活用形为什么是后项的接入口 |
| 助词与成分 | 格助词如何标记角色；は和が如何分工；提示、限定与底层格关系如何叠加 |
| 修饰与小句 | 修饰语为什么在名词前；从句为何常用普通形；小句如何连接、引用和名词化 |
| 态、时体与视角 | 自他动词与参与者结构；存在句；进行与结果状态；可能、被动、使役；授受视点 |
| 语气与文体 | 命题外层如何叠加判断；普通体、敬体与敬语如何区分；未然形、连用形等传统术语是什么意思 |

原因、目的、条件、让步、比较、愿望、许可、推测、评价和 N2/N1 固定表达都是具体语法项目，不再作为“基础规则”重复列出。它们继续由 741 条语法卡负责接续、意义、用法和例句。

## 等级规则

每条基础规则只标“首次需要系统学习的等级”。后续等级继续使用前面的底层知识，但不把 N5 条目重复标成 N4、N3、N2、N1。

底层系统主要在 N5、N4 建立；书面否定意志／推测「まい」首次标为 N2。筛选 N3 或 N1 时可能没有新增底层规则；这不表示高级学习者不需要基础，而是表示高级阶段继续复用此前建立的系统。每条只标首次系统学习的等级，不把 N5 条目重复标成 N4、N3、N2、N1。

## 与语法辞典的分工

- 基础框架：解释共同机制、判断步骤、活用表和句子层级。
- 语法辞典：解释某个具体接续的意义、语气、限制、例句和近义辨析。
- `relatedGrammarIds`：只提供从底层规则到代表性语法卡的跳转，不在基础页复制语法卡例句。
- 语法卡接续中的“未然形、连用形、终止形、连体形、て形、ない形、ます形、辞书形、可能形、被动形、使役形、命令形”等术语可点击，直接打开各自的独立词条；基础页顶部另有“动词全部变形（22 条）”固定入口。
- 基础框架不进入语法 FSRS，不写入 `grammar_progress`，也不制造第二份学习进度。

## 维护检查

- `relatedGrammarIds` 必须指向现有语法卡，测试会阻止失效 ID。
- 表格每行单元格数量必须与表头一致。
- 22 种动词形式必须各有独立 ID、构成表、至少四项结构提示和至少四项易错点；测试会阻止退回单张总表。
- 页面用“动词、名词、小句、形容词”等完整名称，不恢复孤立的 `V/S/N/A` 缩写。
- 不允许重新加入按原因、条件、让步、推测等语义命名的“框架规则”。
- 新增基础规则前，必须说明它能解释哪些不同语法项目的共同机制；仅能对应一两个固定句型的内容应留在语法辞典。
