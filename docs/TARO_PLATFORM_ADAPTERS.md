# Taro 微信平台接口适配表（W4）

本文已按 `tmp/codex-w4-review.md` 的 Claude 审核意见修订并获准实现。目标是让 Taro 继续运行 `frontend/src` 的页面和业务逻辑，只在 `.weapp.*` 文件或 Taro alias 中接入微信能力。网页逻辑只有确实需要暴露接缝时才改，并逐项证明网页登录与同步行为不变。

## 实现约束和验收边界

- 所有小程序平台行为放在 `*.weapp.*` 或 `taro-spike-2/config/index.js` 的明确 alias。业务调用沿用网页源文件；若需要给网页源文件加接缝，逐项列出，并运行 `frontend` 全部 check / lint / test 证明网页无回归。
- 预期的网页源码接缝限于同步 session API 与必要 UI 调用：新增 Mini Program 登录 / 邮箱关联入口，让现有同步层保存 Worker 回包并发出 `CLOUD_AUTH_EVENT` / 自动同步；网页既有 `/wechat-app` 登录和 `/link-wechat-app` 关联路径保持原样。Canvas 如需共享绘图算法，平台差异只能经 `.weapp.*` 实现，网页 Canvas 仍走现有代码。
- 复用原生 runtime 时，先清掉或隔离其对 `wechat-miniprogram/src/shared/web.js` 的依赖；路线 A 最终必须只有 `frontend/src/lib` 一份数据库 / 业务模块实例。
- `wx.requestSubscribeMessage` 必须由用户点击处理器同步调用，不能放在 `await` 之后；按 `config.release.reminders` 和模板配置关闭时不露出入口。
- `config.release.purchase` 属于 `taro-spike-2` 自己加载的发布配置：适配器读取同名字段，仅字段严格为 `true` 才可进入原生 `runtime/payment.js`；字段不存在 / 非布尔 true 时关闭。这样 `taro/main` 尚未带有 `codex/release-prep` 的配置改动时也默认关闭。
- 支付保留订单服务端验证和沙箱流程；任何支付状态都不由客户端回调单独判定。
- 微信登录回包必须交给网页同步层的 session 保存 / 事件 / 自动同步入口；当前原生 `runtime/auth.js` 把 token 记在原生共享数据库状态中，不能直接把它当作 Taro 的 session 接口。若 `sync-api.ts` 需要暴露最小保存接缝，该改动单独列出，并验证网页登录路径和行为不变。
- iPhone 微信小程序没有网页 `sessionStorage`；Taro 入口只提供页面进程生命周期内的内存实现，供“今天完成”庆祝去重。学习数据库和登录 token 不放入这个内存存储。
- 分享 Canvas 的 `.weapp` 适配使用 `wx.createOffscreenCanvas` / `canvas.createImage` / 微信文件系统写 PNG；不得让网页侧 `new Image`、`FileReader` 或 `Audio` 落进小程序运行路径。头像页目前不在 Taro W4 小程序路由 / 分包清单中，若后续接入，必须先提供 `wx.chooseMedia` + 文件系统读取的适配页，不能复用网页文件输入框。
- `taro-spike-2/scripts/check-cloud-transport.mjs` 是构建产物门禁：递归扫描 `dist/**/*.js`，客户端不允许出现 Worker 域名或字面量 HTTPS 请求；云函数源代码不进入小程序代码包。
- API audit (`tmp/miniprogram-api-audit.py`) 可能在压缩包里统计库实现和不可达 Web 分支的标识符。对 `Blob` / worker / stream 的逐项证据、Taro 内置 `URL` 与性能 API 等解释记录在 [`docs/TARO_RUNTIME_API_AUDIT.md`](TARO_RUNTIME_API_AUDIT.md)；不可把扫描器计数直接当成设备运行证据。
- 本表批准后实现。W3 提供 localStorage / Capacitor 文件系统底座；若 W3 尚未合入，W4 可临时依赖既有 polyfill，但不另造接口。W4 提交留在 `taro/w4-wx`，Claude 审核后再合入 `taro/main`。
- 微信开发者工具固定使用 W4 自动化端口 **9450**，复用 IDE 时不关闭 IDE、不切换别人的项目窗口。完成后在开发者工具跑通登录 → 云同步并截图；支付只在预览码与真机沙箱验证，生成预览码后停止，列出用户需在手机完成的步骤。
